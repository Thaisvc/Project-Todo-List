# Todo List 📝✔️

Projeto de estudo desenvolvido durante a formação em **Desenvolvimento Web da Trybe**.  
Uma aplicação web de **lista de tarefas** construída com **HTML, CSS e JavaScript**, que permite ao usuário adicionar, marcar como concluídas e remover itens de uma lista.

---

## 💡 Sobre

O *Todo List* é uma página interativa onde você pode:

✔️ Digitar uma nova tarefa  
✔️ Adicionar à lista de tarefas  
✔️ Marcar tarefas como concluídas  
✔️ Remover tarefas finalizadas  
✔️ Ver mudanças refletidas instantaneamente na UI

Esse projeto fortalece a prática de:

- Manipulação da DOM com JavaScript  
- Eventos (clique, submit)  
- Atualização dinâmica de conteúdo  
- Estruturação semântica de HTML  
- Estilos com CSS responsivo

---

## 🛠 Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript (DOM, eventos)

---

## 📌 Funcionalidades

### ✍️ Adicionar tarefas

Digite uma tarefa no campo e clique em *“Adicionar”* — ela aparece na lista.

### ✅ Marcar como concluída

Clique na task para marcar ou desmarcar como concluída.

### 🗑️ Remover tarefas

Botão para remover tarefas específicas ou limpar todas tarefas concluídas.
